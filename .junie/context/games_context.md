### Games Context Index

Mini-games available within the GodotOS interface.

| Game | Main Components | Description |
|------|-----------------|-------------|
| **Godotris** | `godotris_game.tscn`, `godotris_grid.gd` | A Tetris clone. |
| **Pong** | `pong_main_menu.tscn`, `pong_ball.gd` | A classic Pong game with single/multiplayer modes. |
| **Snake** | `snake_scene.tscn`, `SnakeBoard.gd` | A classic Snake game. |
| **Super Bit Boy** | `bit_boy_player.tscn`, `level_1.tscn` | A 2D platformer game. |

#### Technical Notes
- These games are integrated as GodotOS applications and typically run in their own windows.
- They are mostly self-contained within the `Games/` directory.
